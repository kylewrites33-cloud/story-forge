# Style Fingerprint

Rules learned from the writer's own edits to agent drafts. Each rule is an instruction, with before → after evidence and a counter.

## Rules
- Cut the second adjective. "the old, cracked bell" → "the cracked bell" · +3 / −0
- End a scene on an action, never a thought. S-002: "She wondered…" → "She locked the shop." · +2 / −0
